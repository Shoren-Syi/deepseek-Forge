# Forge 终端工作台分区

工具、对话和状态检查采用独立区域。工具区复用原生会话面板与标签生命周期，上方最多同时显示三个功能；右侧检查器单独绑定主会话，切换工具时不会改变它的数据来源。输入与对话保留原生编辑、附件、模型选择和停止能力。

分屏上限由面板控制器、存储操作和拖放共用一个常量。共享渲染器按水平分栏模型渲染所有列及相邻分隔线，标签内容仍是固定 React 子节点，避免终端和浏览器内容因分栏被重新挂载。空引导页直接承接第一个功能。

设置入口复用原生注册命令，任务设置入口展开检查器的对应明细。辅助执行保持独立会话，渲染结果和状态时不公开内部请求。三方推理强度滑条通过真实模型目录及选择接口接入，不建立另一套模型或任务状态。
