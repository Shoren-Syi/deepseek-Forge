# 终端工作台交付

上方是工具区，下方是对话与命令输入，右侧是固定的工作检查器。工具区左侧放置项目／会话、文件、终端、Diff、设置及辅助任务入口；默认高度约为窗口的 30%。检查器宽约 240px，不再在工具区重复提供检查器按钮。

工具区最多同时显示三个功能。空引导页由第一个功能接替，不占额外的分屏名额。分隔线可以拖动，工具、对话和检查器各自滚动；长代码支持横向查看。启动时收起项目导航，可从工具栏按需展开。输入框采用等宽文字、提示符和线框，保留附件、访问模式、任务设置、模型选择与停止等原生操作。

任务设置按钮直接展开固定检查器内的设置项。全局设置按钮调用原生设置命令。辅助任务仍独立执行，不把内部请求写入主会话。默认快捷键为 Ctrl+Alt+I 打开任务设置、Ctrl+Alt+Shift+A 打开辅助任务；避开原生 Ctrl+Alt+A 归档键。

集成 npm 发布版 dsh-thinking-effort-slide-bar 1.5.5，依赖及启动清单均属于 Forge 副本。滑条使用真实模型目录和原生选择接口。像素鲸鱼参考 ccch1mneyyy/dsh-TUI，素材来源与许可保留在 UI 包的 THIRD_PARTY_NOTICES.md。
