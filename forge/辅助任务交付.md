# 独立辅助任务

底部“辅助任务”入口打开右侧专用区域。工作区摘要与记录经验在这里提交，显示提交状态、执行结果和任务记录。内部提示、推理和工具参数不会出现在结果区域或主会话中。

每次执行创建一个新的原生会话，不复用主会话上下文，不把结果自动发回主会话。工作区摘要从项目文件读取信息；记录经验只携带提交时最近八条用户／助手文字，最多 24000 字符，不携带工具参数和推理。辅助任务使用应用默认模型，与来源任务共享工作目录。

关闭面板后任务继续执行，重新打开或刷新后从原生会话记录恢复。普通会话列表不展示内部辅助会话。停止、权限确认与用户问题仍使用原生能力，均作用于辅助任务。

验证：相关 TypeScript 和 UI 构建通过，77 项针对性测试通过。便携版实际完成一次工作区摘要，结果回到独立面板；来源会话维持 4 个回合、14 个步骤，没有新增辅助指令。原有 DSH 未修改。未运行全仓库测试，权限确认入口通过组件测试覆盖，未额外制造真实权限请求。
