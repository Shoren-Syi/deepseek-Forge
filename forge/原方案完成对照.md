# 原方案功能对照

参考：D:/codex/2026-10-11/referenced-chatgpt-conversation-this-is-an/outputs/DeepSeek_Forge_V1_Engineering_Blueprint.html。

执行用户后续的精简要求：功能落地，复用原生能力，不照搬独立治理平台、反复审查或第二套会话数据库。此前 P10 只是交付拆分；此表按原方案的实际功能对照。

| 原方案功能 | 当前实现 |
| --- | --- |
| 独立 Windows 产品、版本与 Profile | 独立源码、应用标识、锁文件与便携运行时；原有 DSH 未改；桌面启动入口共用 ForgeData |
| Agent 执行、权限、取消与续接 | 原生单一循环、Sandbox、交互请求、事件日志与恢复；停止入口始终可用 |
| 专业代码能力 | 文件/Patch、rg、Git Diff、TS/JS LSP、相关检查；保留用户改动 |
| 工作区发现 | 一键按需生成 .forge/WORKSPACE.md，记录根目录技术栈、包管理器、检查命令、规则与未提交状态，不扫描全仓库 |
| Context 优化 | 固定工作提示、稳定工具集、相关检索、原生压缩与长结果裁剪，原文仍可定位；摘要与项目经验按需读取 |
| Router | 配置真实模型目录中的简单/复杂角色与推理强度，新会话首轮用规则选择；不调用分类模型、不覆盖手动选模、不改全局默认 |
| 执行预算 | 会话步骤、Token、按单价估算的金额预算；达到已用上限后暂停下一步，可修改预算继续；缺价不猜测 |
| Economy | 按实际模型拆分 Usage、缓存、重试与切换；用户单价有来源、按币种估算；失败尝试入量、推理不重复计费 |
| 成本模拟器 | 工作检查器内可调任务成本和假设成功率，单独显示单位成功成本，不作为实测数据 |
| 防止失败被冒充成功 | 结束、暂停、停止、等待与错误分别呈现；工具结果、Diff 与日志可查，不把结束等同成功 |
| 重试与止损 | 复用原生传输重试、重复调用提醒、超时、取消与预算；不增加失败数据库或审查 Agent |
| 长期记忆 | 用户点击记录已确认的约束/决策/已验证修复，保存在项目 .forge/MEMORY.md；标明依据、版本、日期，作为资料按需读取 |
| 历史检索 | 原生、工作区授权的会话检索和历史读取工具，无独立向量服务 |
| Workbench | 工作区/会话导航、活动、文件、PowerShell 7、Diff、日志检索/错误筛选、常驻检查器、主题缩放与原生布局保存 |
| 快捷操作 | 原生文件/终端/命令与快捷键设置；Ctrl+Alt+I 打开 Forge 任务设置，支持原生改绑 |
| 全能能力 | Code/File/Terminal/Browser/Desktop/Office/Skills/MCP 按会话选择；工具契约在任务进行中稳定 |
| 外部服务 | 原生 MCP 接入；自带官方文件服务与普通依赖目录，移动应用后可重绑 D 盘目录 |
| 数据与 API | 原生日志为执行事实，控制项在原生设置，指标是日志投影；按公开接口接入，不建七张治理表 |
| 工程与交付 | 独立 pnpm、锁定依赖、四进程运行包打包、完整 Windows 便携目录、使用说明与本地样例 |

## 根据用户要求采用的取舍

原文建议的 Guardian 控制器、证据数据库、风险矩阵、独立成本账本、固定“必须验证才完成”门禁，已用原生状态、权限、日志、Diff、预算和相关检查替代。自动语义分类、多 Agent 互审、向量记忆和高频模型切换不默认增加。原文中统计显著性和大规模评测不作为本次小型本地产品交付前置门槛。

## 不伪造的边界

配置单价计算的是估算，不是账户账单；调用层预算不能撤销已发出的请求费用。没有官方单价来源时不填造数据。一次任务的 Token 降低不代表总体提速。带账户的第三方 MCP 仍需用户提供连接，桌面图片任务需要模型图片能力，Windows 沙箱子进程管道限制继续保留。
