# Forge 工作台扩展

终端工作台分为上方工具区、下方对话区和右侧固定检查器。工具区左侧集中放置项目／会话、文件、终端、Diff、设置及辅助任务入口，默认高度约为窗口的 30%，最多同时显示三个功能。检查器宽约 240px，各功能内容可以独立滚动。输入、停止、历史和工具执行继续沿用原生能力。

检查器直接读取会话状态、当前模型、工具活动、`sessionStats` 与 `tokenUsage`。已取消回合显示“已停止”，原生交互请求显示“等待输入”；不将回合结束标记为任务成功。没有用量来源时显示暂无数据。

执行日志消费原生 Chat 装配结果，报错默认展开，其他参数与输出按需展开，并可打开原生工具详情。Diff 入口打开最新有改动回合的原生对比面板；没有改动记录时保持禁用。

用量显示输入总量、未缓存输入、缓存读取与缓存写入。模型和工具累计耗时来自原生 sessionStats；并行工具的累计耗时不代表整轮墙钟耗时，不用于推算账单。

显示文字在中英文词典中维护，界面遵循原生主题与缩放。关闭 Forge Profile 中的 `forge-ui` 即可移除扩展。

日志支持按名称、参数和文字输出搜索，以及只看错误。筛选仅影响当前已载入的显示，不改变会话数据与模型决策。

输入栏的任务设置入口可在首轮前配置会话预算和规则路由。检查器按实际模型展示 Usage，可保存带来源的用户单价并计算费用估算；假设成功率模拟器单独标明，不作为实测数据。暂停状态不显示任务成功。

工具栏“辅助任务”打开独立结果面板。工作区摘要与记录经验每次创建新会话，沿用原生执行、停止和持久化，将资料保存为项目内的 `.forge/WORKSPACE.md`、`.forge/MEMORY.md`；提交状态、结果和历史在面板展示，不渲染内部请求或推理。工作目录沿用来源会话，模型采用应用默认配置。记录经验只携带提交时最近八条用户／助手文字，最多 24000 字符，不复制工具参数与思考内容。任务结果不自动写回来源会话，辅助会话不进入普通会话导航。`forge-aux-<来源会话>--<类型>-<UUID>` 是辅助任务的保留标识格式；关联和历史来自原生会话目录，不建立第二份任务数据库。

## Model Experience

检查器与监控只展示现有事实。辅助任务仅在用户点击时调用模型，内部请求保留在独立会话日志中以支持恢复与诊断，不追加到用户的主会话。关闭面板不会取消执行，重新打开可以查看结果。

需要权限确认或补充信息时，在结果区域挂载原生交互入口，但不挂载辅助会话的消息列表。停止操作只作用于选中的辅助任务。目录和项目文件仍与来源工作区共享，会话隔离不等于文件副本。

## Known Limitations and Deferred Work

费用价格没有可靠来源时不估算账单。执行日志展示当前已载入的会话窗口；完整历史与更早日志沿用原生会话入口。Diff 的比较数据生命周期沿用上游实现，不增加独立快照存储。
