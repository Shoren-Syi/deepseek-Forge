# Forge 运行时插件

在原生提示装配中注册 Profile 提供的工作要求，执行仍由 Harness 完成。插件不接管模型循环、工具权限、取消或会话持久化。

同一插件入口按 `role` 注册作用域工作提示或全局控制。控制项保存在原生设置：每会话的步骤、Token、费用估算预算，真实模型目录中的路由角色，以及带来源的每百万 Token 单价。卸载使用 Cordis effect 的原生清理路径。

规则路由只为未手动选模的新会话首轮选择模型，不改变全局默认、不新增分类模型调用。后续请求保持原生选择，用户可随时手动切换。预算检查已用量并暂停下一步；金额预算缺少同币种单价时暂停。它们是调用层控制，不是供应商硬限额。

`forgeEconomy` 从原生请求和 Usage 事件按模型汇总，部分用量被最终用量替换，重试尝试单独累计。推理 Token 不重复计费，没有第二套成本数据库。编程预设复用原生、工作区授权的会话检索工具。

通过 `forge/Start-Forge.ps1` 使用独立数据目录启动。UI 位于 `packages/client/ui-forge`。

## Model Experience

把 Profile 的工作要求放在一个顺序固定、禁止插值的系统提示段内。不会为任务分类、会话标题或逐步审查额外请求模型；工具执行与上下文压缩沿用原生能力。

## Known Limitations and Deferred Work

未知价格不估算，用户提供的单价只产生估算。预算无法撤销已经发出的请求费用。工作提示不代替权限，也不为普通任务增加验收控制器或独立治理平台。
